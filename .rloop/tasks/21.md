Investigate how the Rust claude-agent-sdk-rs exposes token usage on Message::Assistant and Message::Result. Specifically determine: (1) whether Message::Assistant exposes a message ID field for deduplication, (2) whether per-message usage fields (input_tokens, cache_read_input_tokens, cache_creation_input_tokens, output_tokens) represent the full conversation history for that turn or are incremental, (3) whether the SDK sends duplicate Assistant messages with identical usage for the same turn (text + tool_use blocks), (4) what the Result message's cumulative totals represent vs the per-message values. Analyze local session logs in .rloop/sessions/ to observe actual token accumulation patterns across turns. Write findings as a brief report in research/05a-sdk-token-investigation.md with concrete examples from real session data.
