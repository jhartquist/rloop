tool.rs has the BuiltinTool enum (24 lines). tools.rs has MCP tool creation (390 lines). Having both `rloop::tool::BuiltinTool` and `rloop::tools::create_tools` is confusing.

## What to do

- Rename `tool.rs` to `builtin_tool.rs`
- Update `lib.rs`: `pub mod builtin_tool;` (or `pub(crate) mod builtin_tool` if only used internally)
- Update all imports across the codebase: `use crate::tool::BuiltinTool` → `use crate::builtin_tool::BuiltinTool`
- Update integration tests if they reference `rloop::tool::`
- Ensure all tests, examples, and clippy pass

## Why

A user importing `rloop::tool::BuiltinTool` alongside `rloop::tools::create_tools` will be confused. Clear naming prevents ambiguity.
