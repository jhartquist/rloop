# Print step/task/session timing, cost, and token metrics

Add observability output to the terminal so every step, task, and session prints duration, API time, cost, and token usage.

## Current State

- `StepResult` already captures `cost_usd`, `duration`, and `model` (step.rs)
- `StepResult` already captures `cc_session_id` (step.rs)
- The session result printing in `main.rs::print_session_result()` only prints branch, completed/failed/skipped tasks
- No per-step or per-task timing/cost output exists
- Token counts are not currently extracted from Claude SDK messages

## What to do

### 1. Extract token counts from Claude SDK stream

In `step.rs::process_stream()`, extract token usage from `Message::Assistant` messages (the SDK provides `usage` fields). Accumulate input_tokens, output_tokens, cache_read_tokens, cache_creation_tokens across the stream. Add these to `StepResult`:

```rust
pub struct StepResult {
    // ...existing fields...
    pub input_tokens: u64,
    pub output_tokens: u64,
    pub cache_read_tokens: u64,
    pub cache_creation_tokens: u64,
}
```

### 2. Print step summary after each step

After each step completes in `session.rs::run_with_retries()`, print a summary line:

```
  step 1/3  3m 42s  api: 2m 15s  $0.12  tokens: 45k in / 12k out
```

### 3. Print task summary after each task

After each task completes in `session.rs::execute_task()`, print a summary:

```
  task 03  done  5m 18s  api: 3m 30s  $0.25  tokens: 82k in / 28k out  (2 steps)
```

### 4. Print session summary at end

In `main.rs::print_session_result()`, print totals:

```
Session 20250206-143022 complete
  Branch: rloop-05
  Completed: [03, 04, 05]
  Duration: 12m 45s  API: 8m 20s  Cost: $0.72
  Tokens: 245k in / 89k out / 12k cache-read / 5k cache-create
```

### 5. Aggregate metrics

Add a `SessionMetrics` struct (or similar) to accumulate per-step metrics into per-task and per-session totals. `SessionResult` should include the aggregated metrics.

## Acceptance Criteria

- Every step prints a one-line summary with duration, cost, tokens
- Every task prints a one-line summary aggregating its steps
- Session end prints total duration, total cost, total tokens
- Token counts are extracted from the Claude SDK stream
- All metrics are also written to the JSONL session log
- Tests cover metric accumulation
