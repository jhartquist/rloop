## Bug

The `title` field in task frontmatter is not quoted when writing task files, causing YAML parsing errors when titles contain special characters like colons, quotes, or brackets.

## Current Behavior

**In `cmd_task_add` (main.rs:495):**
```rust
let mut fm = format!("---\nid: {id}\ntitle: {title}\nmodel: {model_name}\n");
```

**In `build_task_file` (main.rs:426):**
```rust
if !task.title.is_empty() {
    writeln!(fm, "title: {}", task.title).expect("write to String never fails");
}
```

Both write the title without YAML quotes, producing:
```yaml
title: Fix: add error handling
```

The colon after "Fix" breaks YAML parsing.

## Fix

Add proper YAML string quoting to both locations:

**In `cmd_task_add`:**
```rust
let mut fm = format!("---\nid: {id}\ntitle: \"{title}\"\nmodel: {model_name}\n");
```

**In `build_task_file`:**
```rust
if !task.title.is_empty() {
    writeln!(fm, "title: \"{}\"", task.title).expect("write to String never fails");
}
```

This produces:
```yaml
title: "Fix: add error handling"
```
