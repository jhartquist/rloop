## Goal

Refactor internals to support concurrent task execution without changing any behavior. All existing tests must pass unchanged. This is pure plumbing.

## Reference

Read `research/06-parallel-dag-implementation.md` for the full design spec. Read current `session.rs`, `log.rs`, `config.rs`, and `task.rs` to understand what changes.

## Changes

### 1. Config: add `max_parallel`

Add `max_parallel: usize` to `Config` (default 1). Add a `[session]` TOML section for deserialization. Update `load_config()`, `to_toml()`, default config template, and config tests.

### 2. Frontier detection

Add `find_ready_tasks(tasks, steps, completed, failed, in_flight) -> Vec<TaskId>` to `task.rs`. Pure function — returns task IDs whose dependencies are all in `completed` and that aren't in `failed`, `in_flight`, or `completed`. Write thorough unit tests: linear chain, diamond, wide independent, all completed, all failed, mixed.

### 3. Channel-based logger

Add `EventSender` (wraps `mpsc::UnboundedSender<Event>`, implements `Clone`) and `spawn_logger()` to `log.rs`. The logger task owns `SessionLogger` and calls `print()` + `log()` for each received event. `EventSender::send()` is best-effort (ignore send errors during shutdown).

### 4. Refactor session to use `EventSender`

Replace `logger: &mut SessionLogger` with `logger: &EventSender` in `execute_dag`, `execute_task`, `run_with_retries`, `finish_successful_task`, `finish_failed_task`. In `run_session_with` and `run_all_session_with`: create logger, call `spawn_logger`, pass `EventSender` to `execute_dag`, drop sender after DAG completes, await logger task handle.

## Approach

Use subagents to conserve context. For example, dispatch parallel subagents for: (a) config changes + tests, (b) frontier detection + tests, (c) channel logger + session refactoring. Each subagent reads the relevant source files and makes targeted changes.

## Acceptance Criteria

- `max_parallel` loads from TOML `[session]` section, defaults to 1
- `find_ready_tasks` has comprehensive unit tests covering all DAG shapes
- `EventSender` + `spawn_logger` works (events sent → received in order)
- All 92+ existing tests pass unchanged
- `cargo clippy --all-targets -- -D warnings -W clippy::pedantic` clean
- No behavioral change — sequential execution preserved
