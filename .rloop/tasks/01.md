Add verification command timeout support. The verifier in loop_/verifier.rs runs shell commands without any timeout — if a verification command hangs (e.g., cargo test in an infinite loop), the entire loop hangs indefinitely. The config already has timeout_seconds but it's not used. Implement timeout wrapping around Command execution in the verifier, using the configured timeout. Add tests for timeout behavior.
