step.rs:249 hardcodes `const CONTEXT_WINDOW: f64 = 200_000.0`. This is accurate for current Claude models but will silently produce wrong context percentages for future models.

## What to do

- Add a method to `Model` that returns the context window size: `fn context_window(&self) -> u64`
- Haiku/Sonnet/Opus all return 200_000 for now
- Update `compute_context_percentage` in step.rs to use model.context_window() instead of the constant
- Remove the `CONTEXT_WINDOW` constant
- Ensure all tests pass

## Why

When Claude ships models with different context windows, the percentage calculation will silently report wrong values. Deriving from the model makes it future-proof.
