Revise the existing rloop task new command to always run an LLM enhancement pass. The command takes a rough description string and uses run_query with structured output to generate one or more well-structured tasks. The LLM receives: project context via setting_sources (CLAUDE.md loads automatically), summaries of all existing tasks (id, title, completed, depends_on), and the user rough description. It gets Read/Glob/Grep tools for codebase exploration. Structured output schema: EnhancedTasks { tasks: Vec<EnhancedTask> } where EnhancedTask { title, description, depends_on, model }. For each returned task: assign next sequential ID, build frontmatter, write .rloop/tasks/NN.md. Git add all new files and commit. Print summary listing all created tasks. Remove the --title flag (LLM generates titles). Keep --model (overrides enhance_model from config), --verification (applied to all created tasks), --depends-on (additional deps for all tasks). If the LLM query fails, fail the command with an error (do not create any files).
