Add rloop::query module with a lightweight LLM query function separate from the heavy execute_step machinery. This is the shared infrastructure for task enhancement, LLM verification, and future HumanQ answer processing. Public API: QueryConfig { model, cwd, tools, setting_sources, output_format }, QueryResult { response, structured_output, cost_usd, duration, input_tokens, output_tokens, events }, and async fn run_query(prompt, config). Non-streaming (runs silently, returns result). Logs all events internally and returns them for the caller to log. Supports optional structured output via schemars JSON schema. Supports optional tools (Read, Glob, Grep). Uses project-level setting_sources. No MCP tools, no complete/context_usage, no interruption, no retry. Port from archive/rstep-era/rstep_v1/src/query.rs. Add pub mod query to lib.rs.
