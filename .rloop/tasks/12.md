# Move `rloop list` to `rloop task list`

Move the `rloop list` command to `rloop task list` for a more consistent CLI hierarchy. All task-related commands should live under `rloop task`.

## Current State

- `rloop list` — top-level command that lists tasks (main.rs:245-272)
- `rloop task new` — creates a new task (main.rs:191-235)
- The CLI uses clap with `Command` enum and `TaskAction` subcommand enum

## What to do

### 1. Add `List` variant to `TaskAction` enum

```rust
enum TaskAction {
    New { /* ... */ },
    Show { id: u32 },      // from task 11
    List,                   // NEW
}
```

### 2. Remove top-level `List` from `Command` enum

```rust
enum Command {
    Init,
    Run { /* ... */ },
    // List removed from here
    Task { action: TaskAction },
}
```

### 3. Move `cmd_list()` logic

The existing `cmd_list()` function stays the same, it's just wired to `TaskAction::List` instead of `Command::List`.

### 4. Update help text

Make sure `rloop --help` no longer shows `list` and `rloop task --help` shows both `new`, `show`, and `list`.

## Acceptance Criteria

- `rloop task list` works and shows the same output as the old `rloop list`
- `rloop list` no longer exists (clean error from clap)
- `rloop task --help` shows new, show, and list subcommands
- `rloop --help` shows init, run, task (no list)
