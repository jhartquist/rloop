Add [task] section to .rloop/config.toml with enhance_model field. Default value is Sonnet. This controls which model rloop task new uses for the enhancement LLM query. Update Config struct in config.rs, add TaskConfig sub-struct, parse from TOML, provide default. The enhance_model is used by rloop task new (always) and is overridable via --model CLI flag.
