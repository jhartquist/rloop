# Print system info banner at session and step start

Print a system information banner at the start of every session and at the start of every step, for logging and debugging purposes.

## Current State

- Session start prints: `▶ session {id} targeting task {id}` (log.rs:114-120)
- Step start prints: `→ task {id}` (log.rs:122-123)  
- `StepResult` already has `model`, `cc_session_id` fields (step.rs)
- The Claude SDK `Message::System` message provides `session_id` and `model`
- No date/time, model ID, or CC session ID is currently printed

## What to do

### 1. Session start banner

When a session starts, print a banner with:

- Session ID
- Date and time (local timezone, human-readable)
- Target task(s)
- Parent branch

Example:

```
▶ Session 20250206-143022
  Date:   2025-02-06 14:30:22 PST
  Target: task 05
  Branch: main → rloop-05
```

### 2. Step start info

When a step begins (after receiving the System message from Claude SDK), print:

- Model being used
- Claude Code session ID
- Step attempt number

Example:

```
→ Task 03  step 1  model: claude-sonnet-4-20250514  cc: abc-123
```

The model ID should be the actual model string from the SDK System message, not just 'Sonnet'. The CC session ID comes from `Message::System.session_id`.

### 3. Log these to JSONL too

Ensure the system info is captured in the session JSONL log, not just printed to terminal.

## Acceptance Criteria

- Session start prints date/time, session ID, target, branch
- Step start prints model ID (from SDK), CC session ID, attempt number
- All info is also logged to JSONL
- Date/time uses local timezone with human-readable format
- Tests verify the banner content
