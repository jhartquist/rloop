If a previous session was killed (SIGKILL, machine crash), git branch rloop-05 fails with "branch already exists" and the error is opaque. Same for worktree branches (rloop-wt-05).

## What to do

- In `create_session_branch` (session.rs:66-69), check if the branch already exists before creating
- If it exists, provide a clear error message: "stale session branch 'rloop-05' exists from a previous run. Delete it with: git branch -D rloop-05"
- In `create_worktree` (git.rs:83-94), check for stale worktree directories and branches
- If stale state is found, either auto-clean or provide an actionable error message
- Add tests for the stale branch case
- Ensure all tests pass

## Why

Users who kill rloop with Ctrl+C during cleanup or experience a crash will hit confusing git errors on their next run. Clear error messages or auto-recovery prevent support requests.
