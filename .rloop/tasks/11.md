# Add `rloop task show <id>` command

Add a `rloop task show <id>` command that prints the full details of a single task — title, frontmatter fields, and the complete markdown description.

## Current State

- `rloop list` shows a one-line summary per task (main.rs:245-272)
- `rloop task new` creates tasks (main.rs:191-235)
- No way to view a single task's full details from the CLI
- Task struct has: id, model, depends_on, verification, completed, description, source_path (and title after task 10)

## What to do

### 1. Add `Show` variant to `TaskAction` enum

```rust
enum TaskAction {
    New { /* ... */ },
    Show {
        /// Task ID to show
        id: u32,
    },
}
```

### 2. Implement `cmd_task_show()`

Print the task's full details in a readable format:

```
Task 03: Implement audio preprocessing

Status:     incomplete
Model:      Opus
Depends on: 01, 02
Verify:     cargo test

---

# Implement audio preprocessing

Read audio files, split into frames, apply FFT to get frequency bins.

## Acceptance Criteria

- Reads .wav files via `hound` crate
- Frames at 1024 samples with 512 hop
...
```

Show:

- Task ID and title (if present)
- Status (completed or incomplete)
- Model
- Dependencies (if any)
- Verification commands (if any)
- Full markdown description body

### 3. Wire into CLI

Match the new `TaskAction::Show` in main.rs and call `cmd_task_show()`.

## Acceptance Criteria

- `rloop task show 3` prints full task details
- Shows all frontmatter fields in a readable format
- Shows the complete markdown description
- Prints helpful error if task ID not found
- Works with and without the title field
