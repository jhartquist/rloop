# Add pre-commit quality checks to dev workflow

Add a pre-commit check script or CI command that runs both `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` before commits. Document this in `CLAUDE.md` under the Development Workflow section.

## What to do

1. Add a `mise.toml` (or `justfile`, whatever the project uses) with a `ci` task that runs:
   - `cargo fmt --check`
   - `cargo clippy --all-targets -- -D warnings`
   - `cargo test`
2. Update `CLAUDE.md` to document the pre-commit workflow:
   - Run `cargo fmt` before every commit
   - Run `cargo clippy --all-targets -- -D warnings` before every commit
   - Reference the CI command for running all checks at once
3. Optionally add a git pre-commit hook that runs fmt + clippy checks

## Acceptance Criteria

- A single command runs fmt check, clippy, and tests
- CLAUDE.md documents the workflow clearly
- Existing `cargo clippy -- -W clippy::pedantic` references are updated to use `--all-targets -- -D warnings`
