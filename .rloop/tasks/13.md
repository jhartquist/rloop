When `rloop task new` creates a task file, it should also `git add` the new file and `git commit` it with a descriptive message (e.g. `task: add task 05 - <title>`). This avoids the user having to manually commit each new task file.

## Changes

- In `cmd_task_new()` in `main.rs`, after writing the task file, run `git add <path>` and `git commit -m <message>`.
- Use the existing `git::git()` helper for the git commands.
- The commit message should include the task ID and title (if provided).

## Acceptance Criteria

- Running `rloop task new "description" --title "Fix bug"` creates the file AND commits it in one step.
- The commit message is descriptive: `task: add 05 - Fix bug` (or similar).
- If no title is provided, the commit message still works: `task: add 05`.
- Existing tests still pass.
