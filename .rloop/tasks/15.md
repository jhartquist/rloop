Ensure the crate passes the strictest combination of our two clippy commands:

```bash
cargo clippy -- -W clippy::pedantic        # pedantic warnings
cargo clippy --all-targets -- -D warnings  # all targets, warnings are errors
```

The combined strictest form is:
```bash
cargo clippy --all-targets -- -D warnings -W clippy::pedantic
```

This means: check all targets (lib, bins, tests, examples, benches), enable pedantic lints, and treat all warnings as errors.

## Current State

- `lib.rs` has `#![warn(clippy::pedantic)]` which covers the library code.
- But tests, examples, and the binary (`main.rs`) may not get pedantic checks since they are separate targets.
- CLAUDE.md recommends `cargo clippy --all-targets -- -D warnings` but doesn't mention pedantic for non-lib targets.

## Required Changes

1. Verify the crate passes `cargo clippy --all-targets -- -D warnings -W clippy::pedantic`. Fix any new warnings that appear in tests, examples, or main.rs.
2. Update the CLAUDE.md lint command to use the combined form.
3. If there are specific pedantic lints that are intentionally suppressed (e.g. `missing_errors_doc` in tests), use targeted `#[allow()]` attributes with a comment explaining why.

## Acceptance Criteria

- `cargo clippy --all-targets -- -D warnings -W clippy::pedantic` passes with zero warnings.
- CLAUDE.md documents the combined lint command.
- All existing tests still pass.
