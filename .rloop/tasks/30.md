# Add elapsed time to live terminal output

Add elapsed time prefixes to the live `SessionLogger::print()` output so users can see timing while a session is running, not just in post-hoc `rloop session show`.

## Context

Task 29 added elapsed time display to `rloop session show` (post-hoc review). But during a live session, the `print()` method in `log.rs` outputs events with no timing information. Users want to see `+0s`, `+1m 34s`, etc. as events stream by in real time.

## Requirements

### Add a start time to `SessionLogger`

Add an `Instant` field to `SessionLogger` that records when the session started:

```rust
use std::time::Instant;

pub struct SessionLogger {
    writer: BufWriter<File>,
    _session_id: SessionId,
    start_time: Instant,
}
```

Set `start_time: Instant::now()` in `SessionLogger::new()`.

### Add elapsed time prefix to `print()`

Change `print()` to compute elapsed time from `start_time` and prefix each event line with it. Use the same formatting style as `session show`:

- `+Xs` for seconds < 60
- `+Xm Ys` for 60+ seconds
- Right-aligned to 8 characters

Example live output (before → after):

```
# Before:
▶ Session 20250207-100000
→ Task 05  step 1  model: claude-sonnet-4-5  cc: abc-123
  tool: Read
✓ task 05 — added feature X
■ session complete → branch rloop-05

# After:
    +0s  ▶ Session 20250207-100000
    +2s  → Task 05  step 1  model: claude-sonnet-4-5  cc: abc-123
   +15s    tool: Read
+1m 23s  ✓ task 05 — added feature X
+1m 24s  ■ session complete → branch rloop-05
```

### Multiline events

Some events print multiple lines (e.g., `SessionBanner` with Date/Target/Branch, or `SessionSummary`). The elapsed prefix should appear on the first line; continuation lines should be indented to the same column with spaces.

```
    +0s  ▶ Session 20250207-100000
           Date:   2025-02-07 10:00:00 PST
           Target: task 05
           Branch: main → rloop-05
```

### Shared formatting

Extract the elapsed-time formatting into a shared helper (if `session show` doesn't already share one) so both live output and `session show` use the same format.

## Acceptance Criteria

- [ ] `SessionLogger` tracks session start time via `Instant`
- [ ] Every event printed by `print()` is prefixed with elapsed time (e.g., `+0s`, `+1m 34s`)
- [ ] Elapsed time is right-aligned to 8 characters, matching `session show` format
- [ ] Multiline events indent continuation lines to align with the first line's content
- [ ] `clippy::unused_self` allow can be removed from `print()` (it now uses `self.start_time`)
- [ ] All existing tests pass
- [ ] `cargo clippy --all-targets -- -D warnings -W clippy::pedantic` passes
