CLI validates --parallel >= 1 (main.rs:204) but config file loading does not. A config with max_parallel = 0 would create a semaphore with 0 permits, deadlocking DAG execution.

## What to do

- In `load_config` (config.rs), validate that `max_parallel >= 1` after loading
- If max_parallel is 0, return an error: "max_parallel must be >= 1"
- Add a test: config with max_parallel = 0 should return an error
- Add a test: config with max_parallel = 1 should succeed
- Ensure all tests pass

## Why

Silent deadlock from a bad config value is the worst kind of bug — the program hangs with no error message.
