Three functions exist in near-identical form in multiple files:

- `format_duration` — log.rs:160 and main.rs:1014
- `format_tokens`/`fmt_tokens` — log.rs:181 and main.rs:274
- `extract_token_usage` — step.rs:239 and query.rs:55
- `compute_tool_lists` — step.rs:138-168 and query.rs:40-52 (core logic duplicated)

## What to do

- Make `format_duration` and `format_tokens` `pub` in log.rs
- Remove the duplicate definitions from main.rs and use the log.rs versions
- Extract `extract_token_usage` into a shared location (e.g., log.rs or a new util module) and use from both step.rs and query.rs
- Extract the set-difference logic from `compute_tool_lists` into a shared helper in tool.rs, used by both step.rs and query.rs
- Ensure all tests pass

## Why

Textbook DRY violation. If token usage JSON field names change, both copies need updating independently. The naming inconsistency (format_tokens vs fmt_tokens) signals copy-paste.
