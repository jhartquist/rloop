Multiple core types are missing standard derives that Rust users expect:

- `Task` (task.rs) — no `Debug` or `Clone`. Forces manual field-by-field copy in session.rs:176-185
- `Config` (config.rs) — only `Clone`, missing `Debug` and `PartialEq`
- `Worktree` (git.rs) — no derives at all, no `Debug`
- `Model` (model.rs) — missing `PartialEq`/`Eq` (forces `matches!()` in tests instead of `assert_eq!`)

## What to do

- Add `#[derive(Clone, Debug)]` to `Task`
- Add `#[derive(Debug, PartialEq)]` to `Config` (requires `PartialEq` on `Model`, `TaskConfig`)
- Add `#[derive(Debug)]` to `Worktree`
- Add `PartialEq, Eq` to `Model`'s derives
- Replace the manual field-by-field Task copy in session.rs with `.clone()`
- Replace `matches!(config.model, Model::Opus)` patterns in tests with `assert_eq!(config.model, Model::Opus)`
- Ensure all tests pass and clippy is clean

## Why

Missing Debug makes diagnostic output impossible. Missing Clone forces manual reconstruction. Missing PartialEq forces awkward test assertions. These are table-stakes for Rust types.
